第一章：Shadowrocket深度解析——不只是代理工具

1.1 什么是Shadowrocket？

Shadowrocket，国内用户亲切地称之为“小火箭”，是一款运行在iOS平台上的网络代理客户端。它诞生于2015年，由开发者Guangming Li独立开发并维护。与市面上其他代理工具相比，Shadowrocket的核心优势在于其强大的协议兼容性和极致的性能优化。

从技术层面来看，Shadowrocket本质上是一个基于规则的路由工具。它能够将设备上的网络流量按照用户自定义的规则，智能地分配到不同的代理服务器或直连通道。这种灵活的架构使得Shadowrocket既能满足普通用户的简单需求，也能应对高级用户的复杂场景。

1.2 核心功能全景图

多协议无缝支持：Shadowrocket支持Shadowsocks、ShadowsocksR、Vmess、VLESS、Trojan、WireGuard等几乎所有主流代理协议。这意味着无论您的服务器使用何种协议，Shadowrocket都能轻松对接。

智能规则系统：内置的规则引擎支持域名、IP、GeoIP、进程等多种匹配方式。用户可以设置“国内直连、国外代理”的智能分流策略，既保证访问速度，又确保隐私安全。

流量统计与监控：实时显示当前设备的网络流量使用情况，包括每个应用的流量消耗明细。这一功能对于管理数据配额和排查异常流量非常有帮助。

局域网分享：Shadowrocket支持将代理连接通过局域网分享给同一网络下的其他设备。这一功能在家庭或办公场景中尤为实用，一台设备配置，全网络设备受益。

第三章：手把手配置你的第一个代理节点

3.1 获取代理服务器信息

在配置之前，您需要拥有一个代理服务器的连接信息。这些信息通常包括：

  • 服务器地址：IP地址或域名
  • 端口号：通常为443、8443等
  • 加密方式：如aes-256-gcm、chacha20-poly1305等
  • 密码或UUID：用于身份验证

如果您还没有代理服务器，可以选择以下几种方式获取： - 自建服务器：在Vultr、DigitalOcean等云服务商购买VPS，自行搭建代理服务 - 购买商业服务：选择信誉良好的代理服务商，购买订阅套餐 - 使用免费节点：网络上存在一些免费的代理节点，但稳定性和安全性无法保证，建议谨慎使用

3.2 在Shadowrocket中添加节点

步骤一：打开添加界面 启动Shadowrocket，点击右上角的“+”号，选择“添加配置”。

步骤二：填写节点信息 在类型选择中，根据您的服务器协议选择对应的类型（如Shadowsocks、Vmess等）。然后依次填写服务器地址、端口、加密方式、密码等字段。如果您的服务商提供了二维码或订阅链接，可以直接扫描或粘贴，Shadowrocket会自动识别并填充所有信息。

步骤三：设置备注 为节点设置一个易于识别的名称，如“美国-洛杉矶-01”，方便后续管理和切换。

3.3 连接与测试

配置完成后，返回主界面，点击节点名称右侧的开关按钮，即可建立连接。首次连接时，系统会提示“Shadowrocket Would Like to Add VPN Configuration”，点击“Allow”并验证Touch ID或Face ID。

连接成功后，状态栏会出现VPN图标。此时可以打开浏览器访问ip.sb或whatismyip.com等网站，确认您的出口IP已变为代理服务器的IP地址。

3.4 进阶配置：规则与分流

Shadowrocket的强大之处在于其灵活的规则系统。通过合理设置规则，可以实现“国内直连、国外代理”的智能分流，避免不必要的流量绕行。

配置方法： 1. 点击主界面底部的“设置”标签 2. 选择“规则”选项 3. 点击右上角的“+”号，添加新规则

推荐规则示例： - 域名规则：.baidu.com、.qq.com → 直连 - IP规则：223.5.5.5、114.114.114.114 → 直连（国内DNS服务器） - GeoIP规则：GeoIP, CN → 直连 - 最终规则：MATCH → 代理（所有未匹配的流量走代理）

通过上述规则，您可以实现大多数国内网站直连访问，国外网站自动走代理，既保证了访问速度，又节省了代理服务器的流量配额。

4.1 通过局域网分享代理

Shadowrocket内置的局域网分享功能，可以让同一WiFi下的其他设备（如电脑、平板、游戏机）通过您的iPhone或iPad接入代理网络。

设置步骤： 1. 确保您的iOS设备已连接代理 2. 打开Shadowrocket，点击底部“设置” 3. 找到“局域网分享”选项，开启开关 4. 查看并记录显示的端口号（默认为1080）

其他设备配置： - Windows/Mac：在网络设置中配置HTTP代理，填写iOS设备的IP地址和端口1080 - Android设备：在WiFi设置中配置手动代理，填写相同的信息 - 游戏主机：在PS4/Xbox的网络设置中，选择“使用代理服务器”，输入相关信息

4.2 分享配置文件给朋友

如果您希望让朋友也使用相同的代理配置，Shadowrocket提供了便捷的配置导出与分享功能。

导出配置： 1. 在主界面长按需要分享的节点 2. 选择“分享”选项 3. 选择“复制链接”或“生成二维码”

导入配置： 接收方只需在Shadowrocket中点击“+”号，选择“扫描二维码”或“从剪贴板导入”，即可自动添加节点信息。

4.3 使用订阅功能批量管理

对于使用商业代理服务的用户，订阅功能是最高效的管理方式。通过订阅链接，Shadowrocket可以自动获取所有节点信息，并支持定期更新。

添加订阅： 1. 打开Shadowrocket，点击右上角的“+”号 2. 选择“添加订阅” 3. 粘贴服务商提供的订阅链接 4. 点击“保存”，Shadowrocket会自动拉取所有节点

更新订阅： 在“设置”中找到“订阅”选项，可以设置自动更新时间间隔（如每24小时），确保节点信息始终最新。

第五章：常见问题与解决方案

5.1 连接失败排查指南

症状一：无法建立连接 - 检查服务器地址和端口是否填写正确 - 尝试更换加密方式或协议类型 - 确认服务器是否正常运行（可ping通服务器IP）

症状二：连接成功但无法访问互联网 - 检查是否开启了DNS污染防护（建议开启“启用DNS”选项） - 尝试更换DNS服务器（如1.1.1.1或8.8.8.8） - 关闭并重新开启VPN连接

症状三：速度缓慢 - 尝试切换其他节点，选择地理位置更近的服务器 - 关闭不必要的后台应用，释放带宽 - 在设置中开启“快速切换”模式，优化连接参数

5.2 电池续航优化

Shadowrocket作为VPN工具，会持续运行在后台，对电池续航有一定影响。以下是优化建议：

  • 在不需要代理时，手动断开连接
  • 在“设置-通用-后台应用刷新”中，关闭Shadowrocket的后台刷新（注意：这可能会影响连接稳定性）
  • 使用iOS的“低电量模式”时，Shadowrocket会自动降低网络优先级

5.3 安全与隐私最佳实践

  • 定期更新：保持Shadowrocket始终为最新版本，以获得最新的安全补丁
  • 使用强密码：为代理节点设置复杂度高的密码，避免使用默认密码
  • 谨慎使用公共WiFi：即使有Shadowrocket保护，也尽量避免在公共WiFi下进行敏感操作
  • 开启杀毒功能：Shadowrocket内置了简单的恶意网站拦截功能，建议在“设置”中开启
